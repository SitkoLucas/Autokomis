# AutoKomis Procforce

Demo prezentacyjne cyfrowego sprzedawcy autokomisu (Procforce).

## Start

```bash
npm install
npm run dev
```

Otwórz [http://localhost:3000](http://localhost:3000).

## Stack

Next.js 16, React 19, Tailwind CSS 4, Framer Motion, TypeScript.

## Uwaga

Wersja demonstracyjna z przykładowymi treściami, opiniami i ofertą.
